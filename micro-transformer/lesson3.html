How does the model know what kind of word comes next?

Lesson 2's fix worked, but it was rigid: every position had its own fixed block of weights, permanently bound to one grammatical role (slot 0 always subject-shaped, slot 1 always verb-shaped). It also needed a hard maximum sentence length decided in advance. Stage 2's sentences no longer all have the same shape — "hunter eats meat ." wants an object next, "hunter sleeps in cave ." wants a location, "fire is hot ." wants an adjective. A fixed per-slot rule can't route between these; it would need to already know which sentence shape it's in before seeing it.

Attention replaces "fixed weights per position" with "weights computed from content, every time." Instead of every word contributing a fixed amount, the model asks a question — a query — and each earlier word offers an answer to that question — a key — and how well they match determines how much that word counts. The word actually deciding what comes next is usually the verb, not the subject, and nothing has to tell the model that in advance — it has to discover it, the same way it discovered embedding clusters in Lesson 1.

The same Wq / Wk / Wv weights are applied to every position — there's no separate weight block per slot like Lesson 2. A sentence of length 2 and a sentence of length 4 use the exact same projections; only the number of keys to compare against changes. That's what "no fixed maximum length" actually buys you. Is this the whole story on real attention? ▾ Not quite, but it's the real mechanism at the smallest honest scale. Two things production transformers add: multiple heads (several independent Q/K/V projections running in parallel, so the model can track several different kinds of relationships at once — not just "which word is the verb," but tense, gender, long-range references, and more), and stacked layers (the output of one attention layer becomes the input to another, letting relationships compose). This lesson uses one head and one layer — enough to see routing happen, not enough to see everything attention is capable of.
